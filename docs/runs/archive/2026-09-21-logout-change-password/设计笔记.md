# 设计笔记 / 轻量原型 — 登出+改密 UI

## 交互草图
```
[登录表单]
   │ 成功
   ▼
[资料卡]  用户名/显示名/Token截断
   ├─ [退出登录] → 调 logout API → 回登录 + banner「已退出」
   └─ [改密表单 旧/新] → 成功 → 清会话 + banner「请重新登录」
                      → 失败 → 表内 alert，保持资料卡
```

## 主路径 3 步
1. 登录拿到 Bearer（memory）
2. 退出：POST /api/auth/logout + clear state
3. 改密：POST /api/auth/change-password → 强制回登录

## 状态机
`loggedOut` ↔ `loggedIn`；改密/登出成功均 → `loggedOut` + info banner
