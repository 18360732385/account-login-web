# 设计笔记 — 账号登录前端

## 方案摘要

单页状态机：`未登录` 显示 `LoginForm`；登录成功后持 Token 拉 `/me`，切换 `ProfileView`。

## 关键决策

1. **代理优先**：默认相对 `/api` + Vite proxy，不依赖后端补 CORS Bean。
2. **Token 仅内存**：本轮不做 localStorage，降低 XSS 持久化面；刷新需重登。
3. **错误统一**：后端 `message` 优先展示；网络异常回退通用文案。
4. **proto=entered**：有真实 UI，走简易交互说明即可，不另起原型仓。
