# 需求：登出 + 改密（前端）

## 功能
1. 登录后「退出登录」：调用 `POST /api/auth/logout`（若可用），清空内存会话
2. 登录后「修改密码」表单（旧/新）：调用 `POST /api/auth/change-password`；成功提示并回到登录页
3. 失败态展示服务端错误；不持久化 Token（memory-only）

## 联调
- 默认 Vite proxy；亦可 `VITE_API_BASE_URL=http://localhost:8080`（后端已加 CORS）

## 验收
- Vitest 覆盖 logout / change-password 成功与失败
- `npm test` + `npm run build` 全绿
