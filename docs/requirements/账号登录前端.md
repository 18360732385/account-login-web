# 需求：账号登录前端

> 配对后端：https://github.com/18360732385/account-login-java  
> 授权：`user_task_2026-09-21-web`

## 1. 目标

提供现代登录 UI，调用 Java JWT API；登录成功后展示 `/api/me` 资料或 Token 截断视图。

## 2. 范围

### 做

- 用户名/密码表单；加载中与错误态
- `POST /api/auth/login` → 持 Token 调 `GET /api/me`
- 环境变量配置 API 基址；Vite 开发代理规避 CORS
- Vitest 覆盖登录成功/失败与已认证 me
- README 说明如何对接 account-login-java

### 不做

- 注册、刷新、持久化会话（本轮 Token 仅内存）
- OAuth / SSO
- 生产级密钥与刷新轮换
